# `ds_msp.ops`

Model-agnostic services built on top of any `CameraModel`: undistortion (`Undistorter`) and
pose estimation (`solve_pnp`, `solve_pnp_ransac`). See
[Undistort images](../how-to/undistort_images.md) and
[Solve PnP on a fisheye](../how-to/solve_pnp_on_fisheye.md) for task recipes.

::: ds_msp.ops
