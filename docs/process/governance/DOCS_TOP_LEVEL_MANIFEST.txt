# Positive allowlist of every entry allowed directly under docs/ (enforced by
# tools/check_docs_zone.py, run in CI on every PR). One name per line, exactly as it appears
# under docs/ (files with their extension, directories without a trailing slash). Blank lines
# and #-comments are ignored.
#
# Why an allowlist and not a denylist: docs/RIG_MULTIOBJECT_IMPLEMENTATION_PLAN.md shipped to
# the public tree for months (added in PR #49) because the only defense was a pre-existing,
# local-only regex denylist of phrasings seen so far. A denylist can always miss a phrasing
# nobody thought to list; an allowlist cannot silently miss anything, because any file NOT on
# this list fails closed regardless of its name or content. Adding a genuinely public doc is a
# one-line, reviewable diff to THIS file, in the same PR that adds it.
#
# Internal/planning content belongs in this repository's local-only planning-notes location
# (git-ignored, never appears here, and is itself listed below only so a developer's local
# checkout with that directory present doesn't spuriously fail this check).
